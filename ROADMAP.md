# Product roadmap

## Delivered foundation

- Full curriculum hierarchy and progress history
- Explainable variable-time recommendation engine
- Timer/manual session backend and refresh persistence
- Skills, project milestones, resources, reflections, analytics, portability
- Password authentication and user data isolation
- Containerized development, migrations, automated CI, and provider-ready configuration

## Next safe increments

1. Add task/resource authoring screens with curriculum revision previews.
2. Add assessment rubrics and evidence review that update demonstrated proficiency.
3. Add session reflection dialog and offline queue/service worker.
4. Add CSV bundles and full JSON import with dry-run validation.
5. Add email verification, password reset, CSRF protection, and Redis-backed distributed auth limits before opening registration broadly.
6. Add accessible Recharts visualizations after enough longitudinal data exists.
7. Introduce an optional, provider-neutral AI assistant behind feature flags, with prompts that never receive credentials or unrelated personal data.
8. Add time-series content after the current statistical and validation foundations.

Career-readiness scoring remains intentionally excluded until it can be expressed as transparent rubric evidence rather than a speculative percentage.
